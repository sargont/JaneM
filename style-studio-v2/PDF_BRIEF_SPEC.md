# Jane.M Style Brief — PDF Specification

The Style Brief PDF is a first-class output, not a screenshot. Generate on-screen brief, WhatsApp handoff and PDF from the same structured result object.

Use A4 portrait with real text and multi-page flow. Include: Jane.M branding; Style Brief title; reference ID; date; occasion/context; style direction; silhouette, neckline, sleeve, length, colour, coverage, fabric and embellishment; inspiration where available; client-provided measurements; budget/workmanship guidance; and a `To confirm with Jane.M` section.

Measurements must be labelled: `Client-provided preliminary measurements — Jane.M must verify before cutting/production.`

Use real Jane.M imagery only. Keep the visual language cream/ivory, burgundy and muted gold with editorial serif headings and clean body text. Prefer print-optimized HTML/CSS or an existing lightweight PDF library; avoid raster screenshot export and heavy new dependencies.
