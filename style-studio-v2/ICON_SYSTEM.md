# Jane.M Custom Icon System

Create reusable fine-line SVG icons with a consistent 1–1.5px optical stroke, muted Jane.M gold, clean geometry and couture illustration influence.

Core icons: occasion/calendar, graduation, bridal, corporate, gala/evening, style/dress form, silhouette, neckline, sleeve, length/ruler, measurements/tape, inspiration/image, fabric/textile, embellishment, fit/tailoring, brief/document, personalised, craftsmanship, made in Lesotho, timeless quality, share and WhatsApp.

Use generic icon libraries only for utility actions such as close, back, next, download, external link and accordion controls. Decorative SVGs should be aria-hidden; icon-only buttons need accessible labels.
